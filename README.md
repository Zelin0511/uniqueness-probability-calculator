# 心理不可替代性概率评估器

这是一个基于论文草稿中“关系意义上的心理不可替代性”模型制作的静态网页工具。它用于帮助用户反思一段关系中的独特性来源，而不是判断一个人的真实价值。

## 在线使用

发布到 GitHub Pages 后，可以直接通过浏览器访问本工具。当前项目是纯静态页面，不需要后端服务。

## 配套文章

论文 PDF 已放在仓库的 `paper/` 目录：

- [我在他人心中独一无二的概率](paper/我在他人心中独一无二的概率.pdf)

## 使用方式

直接打开 `index.html` 即可使用。项目不需要安装依赖，也不需要构建步骤。

如果部署到 GitHub Pages，把本仓库发布为静态站点即可。

## 模型变量

工具使用五个核心变量，每个变量由用户按 0 到 10 评分：

- `E` 情感强度：亲近、信任、依恋、思念和情绪牵动的程度。
- `I` 互动持续性：互动频率、关系时长和稳定出现于生活中的程度。
- `M` 共同记忆重要性：是否共同经历了重要阶段、关键事件或高情绪强度时刻。
- `R` 角色稀缺性：你承担的理解、陪伴、支持或见证功能是否难以由他人替代。
- `S` 自我叙事参与度：对方讲述自己是谁、如何变化、为何选择时，是否难以绕开你。

## 计算方式

每个变量先从 0-10 标准化到 0-1，然后进入逻辑函数模型：

```text
z = w1E + w2I + w3M + w4R + w5S + w6EM + w7RS + w8MS - b
P = 1 / (1 + e^(-z))
```

当前权重是理论型默认值，并未经过实证数据校准。后续版本可以通过问卷数据或访谈编码来调整权重。

## 项目边界

本工具只用于理论模型演示和自我反思，不用于判断真实关系价值、诊断心理状态或替代专业咨询。结果越高，只表示模型认为这组关系变量更接近“心理不可替代性”的条件；结果越低，也不表示你这个人不重要。

## 结果页提示语

工具在结果页保留了一段面向用户的提示：

> 你本身是独一无二的，但这并不意味着你在每一个人心中都无可替代。也许你来到这里，是因为失望、不确定，或只是想确认自己是否重要。无论原因是什么，我都想告诉你：大多数关系都有阶段性，一个人在别人心中的位置会变化，但这并不削弱你的价值。请把一点注意力还给自己，让自己过得轻一点、快乐一点。
